SQL help library

Quick answers to the things learners often get stuck on.

Why do I get “no such table”?

The table name in your query does not exist in the current database, or it is spelled differently. Open Database tables in Practice or Playground and copy the exact table name.

SELECT name FROM sqlite_master WHERE type = 'table';
What is the difference between WHERE and HAVING?

WHERE filters individual rows before grouping. HAVING filters groups after GROUP BY has created them.

SELECT city, COUNT(*)
FROM students
GROUP BY city
HAVING COUNT(*) > 1;
When should I use a JOIN?

Use JOIN when the information you need is stored in more than one related table. Match the key columns that connect those tables.

SELECT students.name, enrollments.status
FROM students
JOIN enrollments
  ON students.id = enrollments.student_id;
Why does “= NULL” not work?

NULL represents a missing or unknown value. Use IS NULL or IS NOT NULL, not an equality comparison.

SELECT * FROM students
WHERE email IS NULL;
What does “ambiguous column name” mean?

More than one table in the query has a column with that name. Prefix the column with its table name or a table alias, such as students.id.

How can I see why my answer is wrong?

Run your query first, compare its output with the expected result, read the question hint, and use this tutor to explain the error or SQL concept. The reference solution becomes available after an incorrect attempt.
